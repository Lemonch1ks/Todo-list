# Todo List

A simple Django web application for managing tasks and tags.

The project allows users to create, update, delete, and complete tasks. Each task can have a creation date, an optional deadline, completion status, and multiple tags. Tags can be reused across many tasks.

## Features

- View all tasks on the home page
- Create new tasks
- Update existing tasks
- Delete tasks
- Mark tasks as completed or not completed
- Add optional deadlines to tasks
- Create, update, and delete tags
- Assign multiple tags to one task
- Reuse the same tag for multiple tasks

## Tech Stack

- Python
- Django
- SQLite
- HTML
- CSS
- Bootstrap
- django-crispy-forms
